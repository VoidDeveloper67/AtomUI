A AtomUI v1.1 Guide Getting Started Quick Start Configuration API Reference Elements Library Methods Config System Notifications Resources Examples Demo GitHub Made by von63rd AtomUI Documentation A modern, feature-rich Roblox UI library for script executors. Build beautiful interfaces with smooth animations, auto-configuration, and 15+ built-in elements. Getting Started AtomUI is a single-file Lua library. Load it via game:HttpGet or require it locally. No dependencies needed. Requirements AtomUI requires a Roblox script executor with support for HttpGet, writefile/readfile, and basic Roblox services. Elements AddToggle On/off switch with smooth animation and color transitions. AddSlider Draggable numeric slider with fill bar and value label. AddDropdown Single-select dropdown with search filter and auto-width. AddMultiDropdown Multi-select dropdown with checkboxes for each option. AddButton Clickable button with optional icon and locked state support. AddKeybind Keybind input with Toggle and Hold modes. AddKeybindToggle Combined keybind and toggle in one row. AddTextInput Single-line text input with placeholder and callbacks. AddColorPicker HSV color picker with preset colors and live preview. AddLabel / AddParagraph Text display with optional word wrapping. AddDivider Horizontal separator line with gradient effect. AddSpacer Configurable vertical spacing between elements. automatically saves and restores element states using JSON files. How It Works Every element with a Flag property is automatically tracked. When AutoConfig is enabled, values are saved every 60 seconds and restored on load. lualocal lib = atom_ui.new({ Name = "My Script", AutoConfig = true, -- Enable auto save/load ConfigFolder = "MyConfigs", -- Custom folder name ShowAutoSaveToggle = true -- Show toggle in settings }) -- Elements with Flag are auto-tracked group:AddToggle({ Name = "Silent Aim", Flag = "silent_aim", -- This value is saved Default = false, Callback = function(v) end }) -- Manual save/load lib:SaveConfig("legit") lib:LoadConfig("rage") Note The config system requires your executor to support writefile, readfile, isfolder, makefolder, and listfiles. Config API Method Description lib:SaveConfig(name) Save current values to ConfigFolder/name.json lib:LoadConfig(name) Load values from ConfigFolder/name.json lib:RefreshConfigs() Returns a table of saved config names Notifications AtomUI includes a built-in notification system with progress bars, icons, and smooth animations. lualib:Notify({ Title = "Success", Description = "Settings saved successfully", Duration = 3, -- Seconds (default: 3) Icon = "rbxassetid://10747361219" -- Optional custom icon }) Property Type Required Description Title string Yes Notification title Description string No Body text Duration number No Display time in seconds Icon string No rbxassetid:// URL Rate Limiting Duplicate notifications within 0.85 seconds are automatically suppressed to prevent spam.
