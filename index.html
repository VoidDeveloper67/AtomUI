AtomUI

A modern, feature-rich Roblox UI library for script executors. Build beautiful interfaces with smooth animations, auto-configuration, and 18+ built-in elements.

Single File No Dependencies Auto Config 18+ Elements Notifications Color Themes
Prerequisites

Requirements

AtomUI is a single-file Lua library with no external dependencies. All you need is a compatible executor.

ℹ
Your executor must support HttpGet, writefile / readfile, and standard Roblox services. Most modern executors (Delta, Synapse, etc.) meet these requirements.
Getting Started

Installation

Load AtomUI with a single loadstring call. No files to download, no setup required.

Lua
local atom_ui = loadstring(game:HttpGet( "https://raw.githubusercontent.com/VoidDeveloper67/AtomUI/refs/heads/main/AtomUI.lua" ))()
Getting Started

Basic Setup

AtomUI uses a hierarchical structure: Window → Section → Tab → Group → Elements. Every UI starts with atom_ui.new().

1

Create a window

Call atom_ui.new() with your config table.

2

Add a section

Sections appear as top-level nav items in the sidebar.

3

Add tabs & groups

Tabs organize content within a section; groups divide a tab into columns.

4

Add elements

Attach toggles, sliders, buttons, and more to any group.

Lua
local lib = atom_ui.new({ Name = "My Script", AccentColor = Color3.fromRGB(2, 133, 255), AutoConfig = true }) local main = lib:AddSection({ Name = "Main", Icon = "home" }) local combat = main:AddTab({ Name = "Combat", Icon = "crosshair" }) local aim = combat:AddGroup({ Name = "Aimbot", Side = "Left", Icon = "target" }) aim:AddToggle({ Name = "Enabled", Default = false, Callback = function(v) print("Aimbot:", v) end })

Quick Start

A complete working example with multiple tabs, groups, and elements — ready to paste and run.

Lua
local atom_ui = loadstring(game:HttpGet( "https://raw.githubusercontent.com/VoidDeveloper67/AtomUI/refs/heads/main/AtomUI.lua" ))() local lib = atom_ui.new({ Name = "AtomUI Demo", AccentColor = Color3.fromRGB(2, 133, 255), AutoConfig = true, ConfigFolder = "MyConfigs" }) local main = lib:AddSection({ Name = "Main", Icon = "home" }) local combat = main:AddTab({ Name = "Combat", Description = "Combat settings", Icon = "crosshair" }) local left = combat:AddGroup({ Name = "Aimbot", Side = "Left", Icon = "target" }) left:AddToggle({ Name = "Enabled", Default = false, Callback = function(v) print(v) end }) left:AddSlider({ Name = "FOV", Min = 10, Max = 800, Default = 120, Increment = 5, Callback = function(v) print(v) end }) left:AddDropdown({Name = "Target", Options = {"Head", "Torso"}, Default = "Head", Callback = function(v) print(v) end }) local right = combat:AddGroup({ Name = "Visuals", Side = "Right", Icon = "eye" }) right:AddToggle({ Name = "Box ESP", Default = true, Callback = function(v) print(v) end }) right:AddColorPicker({Name = "Color", Default = Color3.fromRGB(255, 0, 0), Callback = function(c) print(c) end }) lib:Notify({ Title = "Ready", Description = "Press RightCtrl to toggle the UI", Duration = 5 })

API Reference

Library Methods

All methods available on the lib object returned by atom_ui.new().

atom_ui.new(config) Create a new UI window ▶
Returns a lib object. Pass a config table with Name, AccentColor, and other options.

local lib = atom_ui.new({ Name = "My Script", AutoConfig = true })
lib:Toggle() Toggle UI open/closed ▶
Toggles the UI visibility. Equivalent to pressing the configured toggle key.
lib:Open() / lib:Close() Explicitly open or close the UI ▶
lib:Close() hides the main window and shows a small toggle button. lib:Open() restores the full UI.
lib:Notify(config) Show a notification ▶
Displays a toast notification. See the Notifications section for the full config table.

lib:Notify({ Title = "Hi", Description = "Hello", Duration = 3 })
lib:SetAccentColor(color) Change the theme color at runtime ▶
lib:SetAccentColor(Color3.fromRGB(255, 0, 0)) — Updates all UI elements to use the new accent color immediately.
lib:SetWatermark(config) Add a watermark overlay ▶
lib:SetWatermark({ Text = "v1.0", Position = "TopRight" })
Use lib:SetWatermarkText("v2.0") to update the text without re-creating the watermark.
lib:SetSearchFilter(query) Filter visible tabs and groups ▶
lib:SetSearchFilter("aim") — Hides tabs/groups that don't match the query. Pass an empty string to reset.
lib:SetESPPreview(enabled) Toggle the ESP preview panel ▶
lib:SetESPPreview(true) shows a side panel previewing ESP styles in real time.
lib:SaveConfig(name) / lib:LoadConfig(name) Manually save or load a config ▶
Saves/loads all flagged element states to ConfigFolder/name.json.

lib:SaveConfig("legit") — lib:LoadConfig("rage")
lib:RefreshConfigs() List all saved config names ▶
Returns a table of config name strings found in the ConfigFolder.

local list = lib:RefreshConfigs()
lib:Destroy() Destroy the UI and clean up ▶
Removes all UI instances from the game and disconnects all connections. Typically bound to a panic keybind.
atom_ui.Demo() Launch the built-in demo UI ▶
Creates a complete demo window showcasing every element type. Useful for previewing the library before building your own script.
API Reference

Config System

AtomUI can automatically persist element states to JSON files. Any element with a Flag is tracked.

⚠
The config system requires your executor to support writefile, readfile, isfolder, makefolder, and listfiles.
Lua
local lib = atom_ui.new({ Name = "My Script", AutoConfig = true, ConfigFolder = "MyConfigs", ShowAutoSaveToggle = true }) group:AddToggle({ Name = "Silent Aim", Flag = "silent_aim", -- tracked by config system Default = false, Callback = function(v) end }) lib:SaveConfig("legit") lib:LoadConfig("rage")
MethodDescription
lib:SaveConfig(name)Save current values to ConfigFolder/name.json
lib:LoadConfig(name)Load values from ConfigFolder/name.json
lib:RefreshConfigs()Returns a table of saved config names

PropertyTypeRequiredDescription
TitlestringYesNotification title text
DescriptionstringNoBody text beneath the title
DurationnumberNoDisplay time in seconds (default: 3)
IconstringNoAsset URL — rbxassetid://...
⚡
