Build beautiful interfaces with smooth animations, auto-configuration, and 20+ built-in elements. Single File No Dependencies Auto Config 20+ Elements Notifications Color Themes PREREQUISITES Requirements AtomUI is a single-file Lua library with no external dependencies. All you need is a compatible executor. ℹ Your executor must support HttpGet, writefile / readfile, and standard Roblox services. Most modern executors (Delta, Synapse, etc.) meet these requirements. GETTING STARTED Installation Load AtomUI with a single loadstring call. No files to download, no setup required. LUA Copy local atom_ui = loadstring(game:HttpGet( "https://raw.githubusercontent.com/VoidDeveloper67/AtomUI/refs/heads/main/AtomUI.lua" ))() GETTING STARTED Basic Setup AtomUI uses a hierarchical structure: Window → Section → Tab → Group → Elements. Every UI starts with atom_ui.new(). 1 Create a window Call atom_ui.new() with your config table. 2 Add a section Sections appear as top-level nav items in the sidebar. 3 Add tabs & groups Tabs organize content within a section; groups divide a tab into columns. 4 Add elements Attach toggles, sliders, buttons, and more to any group. LUA Copy local lib = atom_ui.new({ Name = "My Script", AccentColor = Color3.fromRGB(2, 133, 255), AutoConfig = true }) local main = lib:AddSection({ Name = "Main", Icon = "home" }) local combat = main:AddTab({ Name = "Combat", Icon = "crosshair" }) local aim = combat:AddGroup({ Name = "Aimbot", Side = "Left", Icon = "target" }) aim:AddToggle({ Name = "Enabled", Default = false, Callback = function(v) print("Aimbot:", v) end }) GETTING STARTED Quick Start A complete working example with multiple tabs, groups, and elements — ready to paste and run. LUA Copy local atom_ui = loadstring(game:HttpGet( "https://raw.githubusercontent.com/VoidDeveloper67/AtomUI/refs/heads/main/AtomUI.lua" ))() local lib = atom_ui.new({ Name = "AtomUI Demo", AccentColor = Color3.fromRGB(2, 133, 255), AutoConfig = true, ConfigFolder = "MyConfigs" }) local main = lib:AddSection({ Name = "Main", Icon = "home" }) local combat = main:AddTab({ Name = "Combat", Description = "Combat settings", Icon = "crosshair" }) local left = combat:AddGroup({ Name = "Aimbot", Side = "Left", Icon = "target" }) left:AddToggle({ Name = "Enabled", Default = false, Callback = function(v) print(v) end }) left:AddSlider({ Name = "FOV", Min = 10, Max = 800, Default = 120, Increment = 5, Callback = function(v) print(v) end }) left:AddDropdown({Name = "Target", Options = {"Head", "Torso"}, Default = "Head", Callback = function(v) print(v) end }) local right = combat:AddGroup({ Name = "Visuals", Side = "Right", Icon = "eye" }) right:AddToggle({ Name = "Box ESP", Default = true, Callback = function(v) print(v) end }) right:AddColorPicker({Name = "Color", Default = Color3.fromRGB(255, 0, 0), Callback = function(c) print(c) end }) lib:Notify({ Title = "Ready", Description = "Press RightCtrl to toggle the UI", Duration = 5 }) GETTING STARTED Configuration All options passed to atom_ui.new(). OPTION TYPE DEFAULT DESCRIPTION Name string "Hub" Window title displayed in the header AccentColor Color3 fromRGB(2,133,255) Primary theme accent color AutoConfig boolean false Enable automatic save/load on startup ConfigFolder string "AtomConfigs" Folder name for config JSON files ShowAutoSaveToggle boolean true Show the auto-save toggle in settings UseConfigSystem boolean true Enable the config UI tab Watermark string nil Watermark text overlay 💡 When AutoConfig is enabled, element states are saved every 60 seconds and restored automatically on the next load. ELEMENTS Element Library 20+ built-in elements — all attached to a Group object. ⊙ AddToggle On/off switch with smooth animation and color transitions ⇿ AddSlider Draggable numeric slider with fill bar and value label ▾ AddDropdown Single-select dropdown with search filter and auto-width ☑ AddMultiDropdown Multi-select dropdown with checkboxes for each option ◈ AddButton Clickable button with optional icon and locked state ⌨ AddKeybind Keybind input with Toggle and Hold modes ⌘ AddKeybindToggle Combined keybind and toggle in a single row ✎ AddTextInput Single-line text input with placeholder and callbacks ◐ AddColorPicker HSV color picker with preset swatches and live preview T AddLabel / AddParagraph Text display with optional word wrapping ─ AddDivider Horizontal separator with gradient effect ↕ AddSpacer Configurable vertical spacing between elements ▰ AddProgressBar Animated fill bar for displaying values between 0–1 with optional percent label ± AddNumberInput Increment/decrement stepper with optional min, max, and step constraints ◉ AddBadge Colored pill label for displaying status or metadata inline ⊞ AddSubTab Horizontal pill-bar sub-navigation inside a tab, each with its own groups and elements 🎨 Custom Background Set a custom background image with blur overlay and tint support ELEMENTS Usage Examples Click any element to expand its config options, methods, and a copy-ready code snippet. Configurable vertical blank space ▶ group:AddProgressBar(config) Animated fill bar for 0–1 values ▶ group:AddNumberInput(config) − / + stepper with optional bounds ▶ group:AddBadge(config) Colored pill for status or metadata ▶ tab:AddSubTab(config) Horizontal pill sub-navigation inside a tab ▶ Custom Background (Config) Set a custom background image with blur overlay ▶ API REFERENCE Library Methods All methods available on the lib object returned by atom_ui.new(). atom_ui.new(config) Create a new UI window ▶ lib:Toggle() Toggle UI open/closed ▶ lib:Open() / lib:Close() Explicitly open or close the UI ▶ lib:Notify(config) Show a notification ▶ lib:SetAccentColor(color) Change the theme color at runtime ▶ lib:SetWatermark(config) Add a watermark overlay ▶ lib:SetSearchFilter(query) Filter visible tabs and groups ▶ lib:SetESPPreview(enabled) Toggle the ESP preview panel ▶ lib:SaveConfig(name) / lib:LoadConfig(name) Manually save or load a config ▶ lib:RefreshConfigs() List all saved config names ▶ lib:Destroy() Destroy the UI and clean up ▶ atom_ui.Demo() Launch the built-in demo UI ▶ API REFERENCE Config System AtomUI can automatically persist element states to JSON files. Any element with a Flag is tracked. ⚠ The config system requires your executor to support writefile, readfile, isfolder, makefolder, and listfiles. LUA Copy local lib = atom_ui.new({ Name = "My Script", AutoConfig = true, ConfigFolder = "MyConfigs", ShowAutoSaveToggle = true }) group:AddToggle({ Name = "Silent Aim", Flag = "silent_aim", -- tracked by config system Default = false, Callback = function(v) end }) lib:SaveConfig("legit") lib:LoadConfig("rage") METHOD DESCRIPTION lib:SaveConfig(name) Save current values to ConfigFolder/name.json lib:LoadConfig(name) Load values from ConfigFolder/name.json lib:RefreshConfigs() Returns a table of saved config names API REFERENCE Notifications Built-in toast notifications with progress bars, icons, and smooth slide animations. LUA Copy lib:Notify({ Title = "Success", Description = "Settings saved successfully", Duration = 3, Icon = "rbxassetid://10747361219" }) PROPERTY TYPE REQUIRED DESCRIPTION Title string Yes Notification title text Description string No Body text beneath the title Duration number No Display time in seconds (default: 3) Icon string No Asset URL — rbxassetid://... ⚡ Rate limiting: Duplicate notifications within 0.85 seconds are automatically suppressed to prevent spam.
